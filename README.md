# eduapp

مخزن آغاز پروژه پلتفرم آموزشی SaaS. [پروپوزال مهندسی](proposal.md) مرجع فعلی دامنه محصول، معماری، امنیت، مدل داده، قراردادهای API و معیارهای پذیرش است. [قرارداد ساختاریافته](proposal.json) برای تقسیم کار مرحله‌ای و ردگیری شناسه‌های الزامات تهیه شده است.

وضعیت کنونی: **طراحی؛ هنوز کد برنامه یا استقرار محصول در این مخزن وجود ندارد.** نسخه ۲٫۰ طرح مهندسی در فایل DOCX ارسالی کارفرما مبنای این پروپوزال بوده، اما فایل اصلی و پیوست‌های HAR/Starter Pack در این مخزن عمومی انتشار نیافته‌اند.

پیش از آغاز ساخت، تصمیم‌های باز بخش ۱۰ پروپوزال و ADRهای Sprint 0 تعیین شوند. هرگونه سرور یا پیش‌نمایش متعلق به محتوای سابق مخزن مستقل از فایل‌های این شاخه است؛ این اسناد به‌تنهایی سرویس موجود را متوقف نمی‌کنند.
