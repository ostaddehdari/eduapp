# آزمون پذیرش Monorepo و CI

با Node و pnpm مشخص‌شده در مخزن اجرا کنید.

```bash
corepack pnpm install --frozen-lockfile --ignore-scripts
node --import tsx --test tests/S02-W01/monorepo-ci.test.mjs
```

چک اجباری `ci / dependency-boundaries` همین آزمون‌ها را روی Pull Request اجرا می‌کند. چهار job برنامه‌ها نیز lint، typecheck، test و build را جداگانه اجرا می‌کنند.

- مسیر موفق، سیاست مخزن و مرزهای وابستگی checkout را بررسی می‌کند و استفاده از قرارداد مشترکِ اعلام‌شده را می‌پذیرد.
- مسیر خطا، import مستقیم از backend، دسترسی frontend به وابستگی دیتابیس، استفاده از قرارداد اعلام‌نشده، حذف مالک مسیر و حذف یکی از چک‌های لازم را رد می‌کند.
- دو مدرسهٔ مصنوعی در مدل خوشامدگویی پنل به‌ترتیب اجرا می‌شوند. ورودی خالی خطای قابل‌پیش‌بینی می‌دهد و اجرای بعدی همچنان نام مدرسهٔ درست را نشان می‌دهد. دامنهٔ این تست مدل پنل است. جداسازی دسترسی داده و نشست در تست‌های مربوط به سرویس‌های مالک آزموده می‌شود.

برای بررسی فعال‌بودن محافظت واقعی شاخه به تنظیمات GitHub مراجعه کنید. آزمون محلی تنظیمات مورد انتظار را با قرارداد مخزن تطبیق می‌دهد.
