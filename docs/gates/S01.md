## عدم نشت Tenant

- W01: عضویت Tenant نامعتبر با `TENANT_CONTEXT_MISMATCH` رد شد.
- W02: Tenant دوم نتوانست parent یا school scope Tenant اول را استفاده کند و state تغییر نکرد.
- W03: connection pool بین دو Tenant reset شد و context قبلی باقی نماند.
- W04: evidence و رابطه سرپرستی خارج از Tenant با خطای پایدار رد شد.

در چهار سناریوی مستقل، نشت داده یا state mutation غیرمجاز مشاهده نشد.

## تصمیم‌های باز محافظت‌شده

- محل و مبنای حقوقی داده کودک: unresolved؛ production مرتبط مسدود.
- سیاست رضایت سرپرست: unresolved؛ جمع‌آوری رضایت واقعی مسدود.
- قرارداد، بودجه و POC Providerها: unresolved؛ فعال‌سازی و ترافیک production مسدود.

این موارد مانع ساخت زیرساخت عمومی S02 نیستند، اما Gateهای مربوط به خود را دور نمی‌زنند.

## Go / No-Go

**GO برای `S02-W01-T01` و فقط مهندسی foundation.**

**NO-GO برای production و Provider activation تا تصویب مستقل.**

## Rollback

این Gate runtime یا داده‌ای را تغییر نداده است. اگر evidence جدید ناسازگار پیدا شود، Gate باز و نسخه جدید گزارش پس از بازبینی ثبت می‌شود؛ rollback سرور لازم نیست.
