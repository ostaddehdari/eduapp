# S05-W01 · کاتالوگ پلن و قیمت

نسخهٔ قرارداد: `1.0.0`؛ شناسه الزام `FR-006`؛ مالک قرارداد و داده: Billing.

| عملیات/رویداد | ورودی و خروجی | وضعیت انتشار |
| --- | --- | --- |
| `GET /v1/plans` (`listPlans`) | `limit`, `cursor`؛ فهرست نسخه‌های منتشرشده، قیمت، ماژول، سهمیه و مدت اعتبار | مسیر Gateway قابل اجرای این ورک؛ انتشار production جداگانه |
| `publish(identity, offer)` | `code`, `expectedVersion`, `priceMinor`, `currency=IRR`, `modules`, `quotas`, `trialDays`, `termDays`؛ نسخهٔ جدید | سرویس داخلی Billing؛ API عمومی ندارد |
| `publishDiscount(identity, discount)` | کد، پلن، درصد و بازهٔ اعتبار؛ کد ثبت‌شده | سرویس داخلی Billing؛ API عمومی ندارد |
| `quote(identity, planVersionId, discountCode?)` | قیمت قابل پرداخت، trial و تمدید؛ بدون تغییر اشتراک | سرویس داخلی Billing؛ API عمومی ندارد |
| `billing.subscription_activated.v1` | شناسهٔ tenant و اشتراک، revision و حداقل دادهٔ لازم | **در این ورک منتشر نمی‌شود**؛ فقط پس از پرداخت verified در ورک‌های بعدی |

| جدول یا مالکیت | دسترسی خواندن/نوشتن |
| --- | --- |
| `commercial_billing.plans`, `plan_versions`, `discount_codes` | مالک `eduapp_commercial_billing_owner`؛ نقش `eduapp_billing_api` فقط SELECT و INSERT لازم، بدون UPDATE/DELETE نسخه و تخفیف |
| `commercial_billing.subscriptions` | مالک Billing؛ خواندن tenant-aware برای تشخیص trial و تمدید؛ RLS اجباری |

| کنش | بازدیدکننده | عضو tenant | ناشر مجاز Billing |
| --- | --- | --- | --- |
| خواندن فهرست منتشرشده | بله | بله | بله |
| محاسبهٔ quote | خیر | فقط پس از `authorizeQuote` و تطابق scope با tenant | صرف نقش ناشر کافی نیست |
| انتشار نسخه/تخفیف | خیر | خیر | فقط با `billing.plan.publish` / `billing.discount.publish` از سیاست مستقل |

خطاهای قرارداد: ورودی نامعتبر `VALIDATION_FAILED`، نسخهٔ کهنه یا انتشار هم‌زمان `CONFLICT`، تخفیف نامعتبر `VALIDATION_FAILED`، دسترسی خارج از tenant `FORBIDDEN` یا `NOT_FOUND`. قراردادهای قبلی با شناسهٔ `plan_version_id` ثابت می‌مانند؛ تغییر ناسازگار به نسخهٔ API/رویداد جدید نیاز دارد.

مالک داده، سرویس Billing و طرح `commercial_billing` است. `GET /v1/plans` نسخه‌های منتشرشده را با صفحه‌بندی عمومی نمایش می‌دهد. انتشار فقط با مجوز مستقل `billing.plan.publish` انجام می‌شود و نسخهٔ بعدی به `expectedVersion` نیاز دارد. سطر نسخه، قیمت ریالی در کوچک‌ترین واحد، ماژول‌ها، سهمیه‌ها، روزهای آزمایشی و مدت قرارداد پس از درج قابل تغییر نیست. نسخهٔ قرارداد خرید قبلی همان `plan_version_id` باقی می‌ماند.

کد تخفیف با `billing.discount.publish` و بازهٔ اعتبار و درصد مشخص ثبت می‌شود. `quote` در محدودهٔ tenant تأییدشده، مبلغ بعد از تخفیف، حق دورهٔ آزمایشی فقط برای نخستین اشتراک و شرایط تمدید را برمی‌گرداند. محاسبهٔ quote هیچ اشتراک یا entitlement ایجاد نمی‌کند؛ پرداخت تأییدشده و نهایی‌سازی سفارش در ورک‌های بعدی S05 انجام می‌شود.

تغییر قیمت فقط با درج نسخهٔ جدید ممکن است. کد تخفیف منقضی یا متعلق به پلن دیگر رد می‌شود. PostgreSQL 17 با RLS اجباری از اشتراک مشتری دیگر در محاسبهٔ trial و تمدید محافظت می‌کند. migration `0013-plan-catalog.sql` فقط ساختار افزایشی دارد و دادهٔ نسخه‌های پیشین را حذف نمی‌کند. نسخه‌های قدیمی بدون شماره تا بررسی دادهٔ موجود قابل خرید نیستند.

درگاه production فعلی تنها پیش‌نمایش ایستا دارد. اجرای migration و فعال‌سازی runtime برای پرداخت نیازمند مسیر انتشار جداگانه با پیش‌شرط و بررسی سلامت است.
