# S04-W04 · Invitations, organization moves and management scope

| Field | Value |
| --- | --- |
| Version | 1.0.0 |
| Requirement | FR-004 |
| Owners | Access for invitations and memberships, Tenancy for organization moves and history |
| Foundations | [Identity and People](S03-W02.md), [Access policy](S03-W03.md), [organization tree](S04-W02.md) |

## API

| Operation | Request and authorization | Result |
| --- | --- | --- |
| `createInvitation` | `POST /v1/invitations`. The selected active membership must have invitation permission for the exact `orgUnitId` and recent MFA. JSON fields are `identityId`, optional `orgUnitId`, and optional integer `expiresInHours` from 1 to 168. | `202` with invitation ID, UTC expiry and queued status. The default lifetime is 48 hours. |
| `acceptInvitation` | `POST /v1/invitations/accept`. Use an authenticated IAM bearer for the invited identity, with or without a selected Tenant. JSON fields are `tenantId` and `token`. | `200` with Tenant, membership and exact organization scope. Select that membership through normal session rotation. |
| `moveOrgUnit` | `POST /v1/org-units/{orgUnitId}/move`. Tenant-wide organization-write permission, current `If-Match` and JSON `parentId`. | `200` with the new revision and ETag. A matching no-op leaves the revision and history unchanged. |

Access stores the invitation token only as a digest and checks expiry again in the redemption transaction. The token is delivered through the configured delivery port. The intended identity must already be active in IAM. The Tenant and the organization unit, when specified, must remain valid at issuance and redemption. Expired, undelivered, replayed, revoked, misdirected and foreign-scope tokens return the same generic `404`. Redemption provisionally grants membership without adding role bindings.

Trusted onboarding callers can supply an internal UUID command key. Same-key retries with unchanged inputs reuse the invitation and token, and confirmed delivery replays return the existing receipt. A different command for that key returns `409`. The delivery adapter deduplicates retries by invitation ID if its first delivery could have succeeded before acknowledgment. API clients cannot supply the internal command key.

## Data and authority

| Actor or owner | Boundary |
| --- | --- |
| Access | Owns invitation digests, expiry, delivery, and redemption into an exact existing or new membership. Supplied resource identifiers convey no authority. |
| Scoped manager | Can invite to their own exact organization unit only if explicitly permitted. They gain no access to child units. |
| Tenant-wide organization administrator | Can move valid units under compatible parents in the selected active Tenant. |
| Tenancy | Owns versioned organization parent changes and append-only `org_unit_move_history`. Its narrow owned invitation predicate checks currently active scope. |

An actual move writes old and new parent references, old and new revision, actor, request ID and UTC time in the same transaction as the parent update and `tenancy.org_unit_changed.v1` event. The existing event contains only the unit ID and revision. All history references use the same Tenant. The old or new parent supplies no role or membership to the moved unit. An existing exact binding to that unit remains valid because the unit ID does not change.
