# S02-W06 · Shared interface and localization

| Version | Requirement | Owner |
| --- | --- | --- |
| 1.0.0 | NFR-003 | Platform UI, public web and control panel |

Both Nuxt public web and React control panel consume the same versioned CSS tokens. Platform UI owns the font, typography, color roles, spacing, focus and motion rules. Each frontend owns its content and interactions. The defaults are Persian, right-to-left, and a Persian calendar, with logical CSS properties for text and layout.

## Data and permissions

| Surface | Contract and permitted access |
| --- | --- |
| Version 1 API and domain events | Existing owners preserve UTC timestamps. Storage, authorization and event processing remain with the owners documented in [S01-W03](S01-W03.json) and [S02-W02](S02-W02.json). |
| Frontends | Present canonical, UTC, Z-suffixed timestamps as Persian dates and times in the Asia/Tehran time zone. Keep the UTC value on the HTML time element for machine readers. Reject malformed input and show an accessible unavailable state. |
| Shared package | Supplies presentation tokens, date formatting and bounded synthetic preview entries. It introduces no HTTP route, event type or table and receives no database or secret access. |
| Preview visitor | Can switch between two fictional schools via the preview URLs. The URL selects a local fixture only. Tenant scope for operational data is determined by the backend boundary and verified membership. |

The acceptance tests cover invalid and ambiguous school parameters, different dates and textual outputs for two fixture schools, time-zone rollover, and a responsive viewport. The preview performs no school-data requests.

## Accessibility and delivery

- Use visible, unobscured keyboard focus and a skip link that moves focus to the main region. Use native links and disclosure controls so Enter, Space, and Tab work without pointer events.
- Provide high-contrast text, labels for navigation and accessible names that come from visible text. Avoid communicating state through color alone.
- Disable the optional disclosure transition when `prefers-reduced-motion: reduce` is active.
- Load the Persian typeface from the application bundle. Use font fallbacks while it loads.

The scope is the base layout and flows exercised in the two frontends. Future operational screens require their own WCAG review.
