## API

Routes use the existing Gateway `/v1` operations and envelope. Responses carrying credentials use `Cache-Control: no-store`. Use TLS for public traffic.

| Operation | Input | Successful result |
| --- | --- | --- |
| `login` | JSON `login`, `password`, optional `tenantId` and `membershipId` | `200` session tokens |
| `requestOtp` | JSON `login`, optional `tenantId` and `membershipId` | `202` random `challengeId` and `expiresAt`, including for unknown or inactive identifiers |
| `verifyOtp` | JSON `challengeId` and six-digit string `code` | `200` session tokens |
| `refreshSession` | `Authorization: Bearer <refresh token>`, optional JSON membership selection | `200` rotated session tokens |
| `logout` | Access bearer JWT | `204` and revocation of the current session |
| `listMySessions` | Access bearer JWT and Gateway pagination | `200` with only session IDs and UTC issue and expiry times in the selected scope |

A session response provides `sessionId`, `accessToken`, `refreshToken`, `accessExpiresAt`, `refreshExpiresAt`, `tenantId` and `membershipId`. The last two fields are null for an identity session awaiting scope selection. Access verifies membership selection on refresh. Active scope is revalidated on authenticated requests. The authenticated identity is the actor. The owner derives tenant and school scope from membership.

Invalid credentials and refreshes return a generic `401`. Invalid, expired and consumed challenges return a generic `422`. The Gateway applies route rate budgets. IAM allows eight password attempts and four OTP requests per normalized subject over fifteen minutes, and limits a challenge to five verification attempts. Owner request limits return `429` with `Retry-After`. An unavailable dependency fails the request with a generic error.

## Data and authority

| Data | SQL owner and allowed access |
| --- | --- |
| Identity and password hash | IAM. Access and Persons may call its bounded active-identity lookup. The hash stays with IAM. |
| Sessions and prior refresh hashes | IAM. Access tokens last at most 15 minutes. Sessions expire after 30 days, with rotation retaining the original deadline. |
| OTP and counters | IAM. Six-digit random secrets expire after five minutes. Storage uses keyed digests. An injected delivery port handles dispatch asynchronously. |
| Membership | Access. IAM calls its owner-scoped read interface using a verified identity and tenant. |
| Revocation evidence | IAM. Append-only `session_revocations` facts use global IAM scope. |

An access JWT carries issuer, audience, expiry, issue time and a random token ID. Authentication verifies these claims, the signature and the digest on the current database session. Passwords use versioned scrypt with a per-password random salt. Rotation locks the session row, stores the consumed refresh digest and issues a fresh pair in one transaction. A reused token revokes the family and records the revocation before returning the generic failure. Application logs exclude bearer tokens, passwords, OTP values and recipient identifiers.

## Event and rollout

IAM owns the existing `identity.session_revoked.v1` event with semantic key `session_id + revision`. The IAM transaction stores the global fact as `sessionId`, `revision`, `reason` and `occurredAt`. Tenant audit projections require an independently verified tenant scope. Platform audit consumption is tracked by S03-W05. The schema extension of the S02 PostgreSQL baseline is `0002-iam-sessions.sql`.

The injected OTP port receives `destination`, `code`, `expiresAt` and an abort signal, which the adapter must honor. A transient process restart can interrupt an in-memory delivery attempt and the client may request a new code. Wire a reviewed provider before offering OTP on a public environment. Browser cookie and CSRF integration belongs to the browser authentication surface. These API routes use explicit bearer credentials.

Verify end to end with `node --test tests/S03-W01/*.test.mjs` against disposable loopback PostgreSQL 17. Recover an already migrated environment using a tested backup or reviewed forward migration.
